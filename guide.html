MSDS 검색 이용 방법

제품명을 확인하고, 제조사별 결과에서 실제 사용 제품의 MSDS를 다운로드하는 방법입니다.

검색 홈사이트 소개이용 방법개인정보 안내링크 오류 안내

제조사별 MSDS 자료실에서는 제품 목록을 페이지별로 살펴볼 수 있습니다. 페이지 안 찾기와 전체 자료 검색은 검색 범위가 다르므로 안내를 확인하세요.

제품 검색부터 PDF 확인까지

  1. 제품명 확인

    용기 라벨이나 구매 서류에서 제조사와 제품명, 등급 또는 제품코드를 확인하세요.

  2. 검색 범위 좁히기

    홈에서 제품명으로 먼저 검색하세요. 결과가 많으면 GS칼텍스 경유처럼 제조사를 붙이거나 XTeer Hybrid 0W-16처럼 등급까지 입력하세요.

  3. 제품과 다운로드 방식 선택

    제조사 이름을 눌러 목록을 펼치고 제품명·등급·색상을 비교하세요. PDF·ZIP 버튼은 공식 파일을 바로 열거나 내려받고, 공식 검색 결과·목록 버튼은 제조사 페이지로 이동합니다. 목록이 길면 50개 더 보기를 누르거나 제품코드로 검색하세요.

  4. MSDS 다운로드

    공식 목록으로 이동했다면 해당 제품의 MSDS 열을 선택하세요. ZIP은 압축을 푼 뒤 해당 문서를 선택합니다. 국문 또는 KOR 표시와 적용 국가를 확인하고, PDF 첫 페이지의 제품명·공급자·개정일을 실제 제품과 대조하세요.

제조사마다 화면이 다를 때

  • GS칼텍스·S-OIL·Kixx 등은 확인된 공식 PDF로 연결합니다. 국문·영문 버튼이 함께 있으면 필요한 언어를 선택하세요.
  • 노루페인트는 색상과 제품코드, 주제·경화제 구분을 확인하세요. KCC는 문서의 언어와 적용 국가를 확인하세요.
  • 한국쓰리엠은 제품명이나 SDS 번호로 검색할 수 있습니다. 문서 번호의 하이픈을 빼고 입력해도 검색할 수 있습니다.
  • SK에너지는 공식 목록의 제품명 칸에 검색어를 입력하고 조회한 뒤 MSDS 열의 저장 아이콘을 누릅니다.
  • 현대 XTeer는 제품군 검색 결과에서 점도 등급을 확인하고 MSDS 열의 Download를 선택합니다.
모바일에서 파일을 열 때

PDF는 브라우저에서 열리거나 다운로드 폴더에 저장될 수 있습니다. ZIP은 파일 앱에서 압축을 풀어 확인하세요. 메일 앱이 연결되지 않아 오류 제보 창이 열리지 않으면 안내된 이메일 주소를 복사해 보내주세요.

검색 결과가 없을 때

제품 라벨의 표기로 다시 검색하거나, 제품군 이름만 입력해 범위를 넓혀보세요. 공식 목록에서 제품이나 다운로드 버튼을 찾기 어렵다면 구매처 또는 공급자에게 요청하세요.
